# 线性代数及其应用

**从向量到矩阵，从结构到几何，从理论到应用。**

这是一份持续编写的中文线性代数讲义，面向专升本计算机专业及工科初学者。从高中熟悉的二维、三维向量出发，逐步进入高维空间、线性方程组、矩阵与线性变换：先看见问题，再理解概念，最后计算验证。

[阅读讲义 PDF](./线性代数及其应用.pdf) · [查看 LaTeX 源码](./main.tex)

## 这份讲义怎么讲

- **让概念有来处。** 从鸡兔同笼的消元思想走向一般方程组，从线性映射的叠加、复合与逆映射理解矩阵运算。
- **把几何直观和数学推导放在一起。** 用向量、平面、坐标架和映射示意图解释定义，配合完整算例与必要证明。数学图主要使用可编辑的 TikZ 绘制。
- **用贯穿案例连接章节。** 短视频推荐从“视频可以写成向量”展开到线性表示、权重求解和矩阵运算；港珠澳大桥的简化工程模型引出 LU、PLU 分解；阿波罗计划与坐标变换案例帮助理解同一个对象的不同坐标描述。
- **区分主线与拓展。** 主线围绕课程基础展开，“选读”与“应用案例”供有兴趣的读者继续阅读。工程参数和推荐规则采用教学简化模型，不代表真实工程设计数据或平台内部算法。
- **配套中英术语表。** 新概念附英文名称，书末按英文字母分组，便于查阅与对照英文教材。

讲解思路参考 David C. Lay《线性代数及其应用》的直观应用导向，以及 Sheldon Axler《线性代数应该这样学》的结构化思路，以本讲义的叙述、算例和配图组织内容。

## 阅读建议

初次学习可从第 0 章开始，沿着“向量 → 线性关系 → 方程组 → 矩阵 → 线性变换”阅读。熟悉高中向量的读者可将第 0 章作为回顾，再进入第 1 章的定义与性质。

复习时可先看本章小结，再回到对应的定义、定理与例题；遇到几何意义不清楚的公式，结合附近的示意图重新理解。选读与案例可以按兴趣穿插阅读。

## 本地编译

项目使用 **XeLaTeX**。本地需有可运行 `xelatex` 的 TeX 环境，以及源文件使用的宏包（包括 `ctex`、`amsmath`、`tcolorbox`、TikZ、`pgfplots` 等）。

源文件指定了以下字体，编译前需确保可用：

- `TeX Gyre Pagella`
- `Noto Serif CJK SC`，含 Bold、Light 字重
- `Noto Sans CJK SC`，含 Bold 字重
- `FandolKai-Regular`

在已配置 GitHub SSH 访问的电脑上获取仓库：

```powershell
git clone git@github.com:YukieMoes/LinearAlgebraLecture.git
cd LinearAlgebraLecture
```

Windows 下在项目目录运行以下命令，或直接双击 `build.cmd`：

```powershell
.\build.cmd
```

脚本执行两遍 XeLaTeX，在 `tmp/build-publish/` 中生成中间结果，成功后更新项目根目录的 `线性代数及其应用.pdf`，并同步生成的术语表。正式 PDF 已随仓库提供；脚本要求该文件存在，请勿在编译前删除。临时编译文件与本地备份不纳入版本管理。
